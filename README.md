# nvim

My Neovim configuration, built on the [LazyVim](https://github.com/LazyVim/LazyVim) starter and managed by [lazy.nvim](https://github.com/folke/lazy.nvim).

## What's configured

- **LazyVim extras** (`lazyvim.json`): clangd, CMake, Python, Docker, Markdown and Git language support; DAP debugging core; nvim-cmp, LuaSnip/mini.snippets, Neogen, Yanky; fzf, dial, inc-rename; Prettier; dot and mini-hipatterns utilities.
- **Python**: Pyright as the LSP and Ruff (`ruff_lsp`); the Python provider points to `~/.venvs/nvim/bin/python`.
- **Jupyter-style notebooks in Neovim** with [molten-nvim](https://github.com/benlubas/molten-nvim) and inline images via [image.nvim](https://github.com/3rd/image.nvim). The two `image.nvim` specs set the backend to `kitty` and to `ueberzug`.
- **Markdown preview** in a floating window with [glow.nvim](https://github.com/ellisonleao/glow.nvim) (`<leader>mg`).
- Options (`lua/config/options.lua`): space as leader, autoformat off, relative numbers, 4-space indentation, system clipboard, `rg` as grep program.
- `matugen_colors.lua`: a color palette table (base/surface/text/accent colors), presumably generated by matugen.

## Key mappings (`lua/config/keymaps.lua`)

| Keys | Action |
|------|--------|
| `<leader>mi` | `MoltenInit` |
| `<leader>ml` / `<leader>mv` / `<leader>mc` / `<leader>me` | Evaluate line / visual selection / operator / cell |
| `<leader>mn` / `<leader>mp` | Next / previous cell |
| `<leader>mo` / `<leader>mh` | Open / hide output |
| `<leader>md` | Delete cell |
| `<leader>mr` / `<leader>ms` | Restart / interrupt kernel |
| `<leader>mg` | Glow Markdown preview |

## Install

```bash
mv ~/.config/nvim ~/.config/nvim.bak   # back up any existing config
git clone https://github.com/Gedankenn/nvim ~/.config/nvim
nvim                                   # lazy.nvim bootstraps itself and installs the plugins
```

Optional dependencies for the extras: `ripgrep`, `fzf`, `glow`, a Python venv at `~/.venvs/nvim` with `pynvim` and `jupyter_client` for molten, and Kitty or ueberzug for images. Plugin versions are pinned in `lazy-lock.json`.
